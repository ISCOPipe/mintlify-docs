Pipeline is organized into department modules under the repo root. Each module contains PHP pages, AJAX handlers, dashboards, and workflow tools specific to that business unit. This guide maps the folders to what they do and highlights the most important entry points.

## Shared infrastructure

Some folders serve the entire application rather than a single department:

| Folder | Role |
| --- | --- |
| `inc/` | Shared PHP includes: authentication, roles, search helpers, Oracle/Canto/ShareFile functions |
| `Classes/` | Reusable PHP classes for document handling, barcodes, and RSS |
| `js/` | Global client-side scripts: search, datatables, camera, address validation |
| `css/` | Global stylesheets including `isco.css` and theme CSS |
| `left/` | Sidebar menu builder with role-based permissions |
| `task/` | Cross-department workflow engine |
| `reports/` | Cross-department reporting tools |
| `react-src/` | Modern React screens embedded in PHP hosts |
| `ext/` | Third-party JS libraries (mentions input, dompdf, lottie) |

<Note>
  When adding a new department page, place it in the appropriate module folder and register it in the sidebar via `left/` if it needs navigation. For React screens, add the entry point to `vite.config.js` and host it from a PHP page in the relevant module folder.
</Note>
