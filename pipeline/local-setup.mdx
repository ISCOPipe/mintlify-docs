Pipeline runs on PHP 8.2 under XAMPP with React bundles built by Vite. This guide takes you from a fresh clone of `iscopipe/pipeline` to a working local copy.

## Requirements

- Windows with [XAMPP](https://www.apachefriends.org/) (Pipeline includes connection files from `c:/xampp/inc/`)
- PHP 8.2 or later with these extensions enabled: `ldap`, `odbc`, `mysqli`, `curl`, `gd`, `fileinfo`, `ctype`, `zip`
- [Composer](https://getcomposer.org/)
- Node.js 20 and npm (matches the CI build)
- Microsoft ODBC driver for SQL Server and network access to ISCO's SQL servers

## Set up

<Steps>
  <Step title="Clone the repository">
    Clone into a folder Apache can serve, such as your XAMPP `htdocs` directory.

    ```bash
    git clone https://github.com/iscopipe/pipeline.git
    cd pipeline
    ```
  </Step>
  <Step title="Install PHP dependencies">
    ```bash
    composer install
    ```
  </Step>
  <Step title="Install Node dependencies">
    ```bash
    npm ci
    ```
  </Step>
  <Step title="Add the connection files">
    Pages include database connection files that are not in the repo, such as `c:/xampp/inc/con_itdb.php` and `c:/xampp/inc/con_kore.php`. Get these from your team lead and place them in `c:/xampp/inc/`.
  </Step>
  <Step title="Map the T drive">
    Some pages read shared files from the `T:/` drive. On Windows, map `T:` as usual. On Linux, set the `T_MOUNT` environment variable to the mount path.
  </Step>
  <Step title="Build the React bundles">
    ```bash
    npm run compile:react
    ```

    This runs `vite build` from `react-src/` and writes bundles to `dist/`. Outside CI, Vite stays in watch mode and rebuilds when you edit files in `react-src/`.
  </Step>
  <Step title="Point Apache at the repo and sign in">
    Configure the Apache document root (or a virtual host) to the repo folder, open the site in your browser, and sign in at `/login.php`.
  </Step>
</Steps>

<Note>
  `.env` is ignored by Git and is generated by a post-checkout hook. If your checkout has no `.env`, ask your team lead for the hook or the file contents.
</Note>

## Add a React screen

1. Create a component folder under `react-src/components/`.
2. Add an entry file in `react-src/` and register it in `rollupOptions.input` in `vite.config.js`.
3. Load the built `dist/<name>.js` from the PHP page that hosts the screen.
