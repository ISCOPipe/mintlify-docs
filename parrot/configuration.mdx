The Parrot worker is configured through a stack of layers: `.chalice/config.json` per-stage defaults, AWS SSM Parameter Store secrets, and local `.env` overrides. This page documents every tunable.

<Warning>
  The repository contains committed secrets (API keys, AWS credentials, connection strings). Never copy secret values into the docs or commit them. Use a local `.env` file and the team's secret store for real values.
</Warning>

## Feature flags and debug switches

| Variable | Source | Effect |
| --- | --- | --- |
| `QUOTE_BUILDER_IMAGE_INGEST` | `config.json` / `.env` | Master switch for image ingestion (#9024). `1` enables PNG/JPG/JPEG/WebP transcription via vision OCR. `0` (default when absent) excludes image attachments entirely. |
| `QUOTE_BUILDER_LLM_DEBUG` | `.env` | When set to `1`, enables verbose LLM request/response logging in the pipeline. |
| `QUOTE_BUILDER_ATTACHMENT_CONCURRENCY` | `.env` | Max concurrent email attachments processed. Default `4`. |
| `QUOTE_BUILDER_MIN_CONFIDENCE` | `.env` | Shared confidence threshold used by junk filter and validation. Default `0.5`. |

## LLM token budgets

`chalicelib/pipeline/config.py` defines per-step `max_tokens` budgets. Override order:

1. `QUOTE_BUILDER_MAX_TOKENS_<MODEL_FAMILY>_<STEP>`
2. `QUOTE_BUILDER_MAX_TOKENS_<STEP>`
3. `MODEL_LLM_MAX_TOKEN_OVERRIDES[model_family][step]`
4. `LLM_MAX_TOKENS[step]`

Example defaults:

| Step | Default tokens |
| --- | --- |
| `description_cleanup` | `4000` |
| `document_classify` | `50` |
| `match_select` | `1536` |
| `structured_search_specs` | `12000` |
| `translate` | `4000` |
| `wall_split` | `4000` |

Retry growth is controlled by `QUOTE_BUILDER_MAX_TOKEN_RETRY_MULTIPLIER` (default `2`).

## Orchestration dual mode

The worker reports results in two modes, controlled by the presence of `orchestration-api-url`:

- **Dev mode**: Orchestration URL is empty. The worker writes progress, completion, and failure directly to DynamoDB.
- **Prod mode**: Orchestration URL is configured. The worker sends S1/S2/S3 HTTP callbacks to the Orchestration API and writes result JSON to S3 for reference.

See `/parrot/orchestration-api` for the Orchestration API contract.
