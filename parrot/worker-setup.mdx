The worker lives in `quote_builder_aws`. The Chalice application and its importable modules are inside **`quote_builder/`**. Paths such as `chalicelib/pipeline/runner.py` in the stage reference are relative to that application directory, not the repository root.

## 1. Install the local environment

Use Python 3.12 or later and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/ISCOPipe/quote_builder_aws.git
cd quote_builder_aws
uv sync
```

The root `pyproject.toml` is a dependency project, not an installable Python package. Test scripts may add `quote_builder/` to their import path. For machine-learning evaluation dependencies, the project defines the `eval-ml` extra; install it only if your chosen evaluation requires it.

## 2. Choose configuration deliberately

Obtain development credentials through your team's access process. Do not copy credentials from tracked configuration or fixture files.

`quote_builder/chalicelib/aws/ssm_config.py` loads SSM parameters at cold start. Resolution is **SSM value, environment fallback, supplied default, then mapped default**. A local environment variable does not override an available SSM value.

| Setting name | Environment fallback | Purpose |
| --- | --- | --- |
| `openrouter-api-key` | `OPENROUTER_API_KEY` | Model provider |
| `openrouter-model` | `OPENROUTER_MODEL` | Model selection |
| `cloudflare-account-id` | `CLOUDFLARE_ACCOUNT_ID` | Document conversion account |
| `cloudflare-api-token` | `CLOUDFLARE_API_TOKEN` | Document conversion token |
| `llama-parse-key` | `LLAMA_PARSE_API_KEY` | OCR provider |
| `es/api_key`, `es/api_url`, `es/index` | `ES_API_KEY`, `ES_URL`, `ES_INDEX` | Catalog search |
| `jobs-table`, `jobs-table-v2` | `JOBS_TABLE`, `JOBS_TABLE_V2` | Job persistence |
| `uploads-bucket` | `JOBS_BUCKET` | Uploaded files |
| `dispatch-queue-url`, `dispatch-queue-name` | `DISPATCH_QUEUE_URL`, `DISPATCH_QUEUE` | Dispatch queue |
| `orchestration-api-url` | `ORCHESTRATION_API_URL` | Internal callback API |
| `orchestration_service_contract/api_key` | `ORCHESTRATION_API_KEY` | Callback authentication |

`SSM_PREFIX` defaults to `/parrot/`. Stage-scoped settings include API version, job tables, upload bucket, dispatch queue, orchestration settings, and the LlamaParse key. Shared settings load from `/parrot/`; stage-scoped lookups prefer the stage prefix and can fall back to the base prefix. Missing or unavailable SSM values can fall back to environment configuration.

<Warning>
An empty orchestration API URL selects direct DynamoDB behavior. A configured URL selects HTTP callbacks. Neither mode is automatically an offline sandbox. Check the resolved development resources before running a full pipeline.
</Warning>

## 3. Start with scoped tests

Use [testing and evaluation](/parrot/testing-and-evaluation) to choose a test. Inspect its imports, fixtures, mocks, and external calls before running it. Unit tests and full document-processing runs have different effects.

The interactive pipeline tool is available as:

```bash
uv run python tests/test_pipeline_gui.py
```

It runs processing, not just a UI preview. Model calls, OCR, search, and configured persistence can require network access and incur cost. Use approved synthetic fixtures. Do not run deployments or a production job to validate documentation.

## 4. Trace an extraction problem

1. Confirm the input format and which ingestion path ran.
2. Compare extracted rows, descriptions, quantities, and units with the source document.
3. Inspect parser-selection metadata before blaming product search for a missing row.
4. Check candidate selection separately from extraction.
5. Review the [matching pipeline](/parrot/matching-pipeline) and [user review guide](/parrot/user-guide).

## Deployment boundary

The deployment application is `quote_builder/`, with stage configuration in `quote_builder/.chalice/config.json`. Deployment changes AWS resources; it is not a local verification step. Review the stage's queue, SSM prefix, tables, and bucket with the service owner before using Chalice deployment commands.
