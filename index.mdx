These docs help ISCO developers understand, set up, and ship the three core internal projects: **Pipeline**, **Parrot**, and **QMD**. Each section explains what the project does, which GitHub repositories it lives in, and how to get it running locally.

## Repositories at a glance

All repositories live in the `iscopipe` GitHub organization.

| Project | Repository | Stack |
| --- | --- | --- |
| Pipeline | `iscopipe/pipeline` | PHP 8.2, React 19, Vite |
| Parrot | `iscopipe/pipeline` (UI), `iscopipe/quote_builder_orchestration`, `iscopipe/quote_builder_aws` | React, Python 3.12, AWS Chalice |
| QMD | `iscopipe/qmd_weld_app_web`, `iscopipe/qmd_weld_app_api`, `iscopipe/qmd_weld_app_windows` | ASP.NET MVC and Web API, UWP |

## Get started

<Steps>
  <Step title="Get GitHub access">
    Ask an `iscopipe` organization admin to add you to the repositories you need.
  </Step>
  <Step title="Clone the repositories">
    Follow the [quickstart](/quickstart) to clone every project from GitHub.
  </Step>
  <Step title="Set up a project">
    Use the setup guide for [Pipeline](/pipeline/local-setup), [Parrot](/parrot/worker-setup), or [QMD](/qmd/setup).
  </Step>
</Steps>
