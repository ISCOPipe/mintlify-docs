This first documentation pass covers 27 application and supporting repositories plus this documentation repository. Each link below points to the exact source snapshot used for this pass. These are inspected branch tips, not a claim about what is deployed.

All source snapshots use `main` except `qmd_weld_app_api`, which uses `stable` because that repository has no `main` branch. The documentation row records the baseline before this update; it is not the commit that publishes this page.

Start with the guide for your task. Follow the commit link when you need to compare a documented behavior with its implementation. Do not copy credentials or live records from source into examples.
